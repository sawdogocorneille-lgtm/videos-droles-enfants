## 📥 Comment utiliser cette structure

### 1️⃣ Ressources (music, images, fonts)

Téléchargez et organisez vos ressources gratuites :

```bash
# Exemple : organiser les musiques
resources/music/background-music/
  ├── funny-01.mp3
  ├── funny-02.mp3
  ├── silly-03.mp3
  └── playful-04.mp3

# Exemple : organiser les images
resources/images/characters/
  ├── rabbit-cute-01.png
  ├── panda-cooking-02.png
  ├── dragon-scared-03.png
  └── cat-silly-04.png
```

### 2️⃣ AI Prompts (générateurs)

Gardez tous vos prompts AI pour générer :

```markdown
# ai-prompts/ideas-generator.md
## Prompt 1: Générer 20 idées
Génère 20 idées de vidéos drôles...

## Prompt 2: Générer scripts
Écris un script de 30 secondes...
```

### 3️⃣ Projects (vos créations)

Chaun vidéo a son dossier :

```bash
projects/project-001-rabbit-basketball/
├── script.md          # Texte du script
├── images/            # Images téléchargées
│   ├── rabbit-01.png
│   ├── court-02.png
│   └── ball-03.png
├── audio/             # Fichiers audio
│   ├── voice.mp3
│   └── music.mp3
└── output.mp4         # Vidéo finale
```

### 4️⃣ Tutorials

Gardez vos apprentissages :

```markdown
# tutorials/editing-tips.md
## CapCut Tips
- Astuce 1: Comment utiliser Auto Cut
- Astuce 2: Comment ajouter des effets
- Astuce 3: Comment exporter en 4K
```

## 🎬 Workflow complet

### Semaine 1 : Préparation

```bash
# Jour 1
- Télécharger les outils (CapCut, GIMP, OBS)
- Créer la structure des dossiers
- Cloner ce repository

# Jour 2-3
- Télécharger 50 musiques gratuites → resources/music/
- Télécharger 100 images → resources/images/
- Télécharger 20 polices Google → resources/fonts/

# Jour 4-5
- Générer 20 idées → ai-prompts/ideas.md
- Écrire 5 scripts → ai-prompts/scripts.md
- Préparer 3 projets

# Jour 6-7
- Filmer la première vidéo
- Monter avec CapCut
- Publier et tester
```

### Semaine 2+ : Production

```bash
# Chaque jour
1. Choisir une idée (5 min)
2. Écrire le script (10 min)
3. Télécharger les images (5 min)
4. Générer la voix (5 min)
5. Monter la vidéo (30 min)
6. Exporter et publier (5 min)

Total : 60 minutes par vidéo
```

## 🔍 Checklist avant publication

```markdown
# Checklist publication

- [ ] Vidéo complète et montée
- [ ] Son clair et facile à comprendre
- [ ] Musique de fond appropriée
- [ ] Aucun bug visuel ou audio
- [ ] Durée optimale (25-60 sec)
- [ ] Sous-titres français (si nécessaire)
- [ ] Format 1080p ou 4K
- [ ] Fichier MP4 exporté
- [ ] Aperçu visionné par au moins 1 personne
- [ ] Hashtags préparés
- [ ] Description écrite
- [ ] Prêt à publier ✅
```
