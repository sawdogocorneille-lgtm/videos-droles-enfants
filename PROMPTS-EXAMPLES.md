# Exemples de prompts AI prêts à utiliser

## 1. ChatGPT - Générer 10 idées de vidéos

**Prompt :**
```
Génère 10 idées de vidéos très drôles pour enfants (4-8 ans).
Chaque vidéo dure 25-40 secondes.
Format :
- Titre
- Personnage (animal mignon)
- Situation comique
- Action drôle
- Fin avec gag

Les vidéos doivent être simples à filmer avec :
- Un téléphone ou une caméra
- Des objets du quotidien
- Un décor simple
- Pas d'effets spéciaux compliqués
```

**Résultat attendu :** 10 idées prêtes à scénariser

---

## 2. ChatGPT - Écrire un script complet

**Prompt :**
```
Écris un script complet pour une vidéo de 30 secondes:

Personnage : un petit panda
Situation : le panda essaie de faire un sandwich
Complication : tous les ingrédients tombent
Gag final : le panda fait un sandwich avec les yeux fermés et c'est délicieux

Format du script :
1. Action 1 - Description détaillée
2. Action 2 - Dialogue si nécessaire
3. Action 3 - Réaction
4. Action 4 - Gag final
5. Durée : 30 secondes

Style : comique, exagéré, enfantin, pas de violence
```

**Résultat attendu :** Script prêt à filmer

---

## 3. DALL-E - Générer un personnage

**Prompt :**
```
Generate a cute, cartoon-style baby panda character:
- Very cute and round face
- Big expressive eyes
- Soft black and white fur
- Standing pose, ready to do something
- Pastel background (soft pink)
- High quality, 4K, illustration style
- Perfect for children's video
- Style: Pixar-like, friendly, adorable
```

**Résultat attendu :** Image PNG haute qualité du panda

---

## 4. Midjourney - Générer une scène complète

**Prompt :**
```
/imagine a cute cartoon rabbit trying to play basketball:
- Small basketball court
- Ball flying everywhere
- Rabbit with funny expression of surprise
- Pastel colors
- Bright lighting
- Children's book illustration style
- 4K quality
--ar 16:9
--quality 2
```

**Résultat attendu :** Image haute qualité pour la scène

---

## 5. Leonardo.AI - Générer un décor

**Prompt :**
```
Generate a simple cartoon kitchen for children's animation:
- Bright colors (yellow, red, white)
- Clean and simple shapes
- A table with ingredients
- Soft shadows
- No realistic details
- Illustration style
- Perfect for a children's video background
- Pastel tones
```

**Résultat attendu :** Image du décor de cuisine

---

## 6. ElevenLabs - Générer une voix enfantine

**Prompt (via interface) :**
```
Text to speak:
"Oh non! Mon gâteau s'écroule! Attendez, ça reste bon!"

Voice settings:
- Language: French
- Voice type: Child boy, 6-7 years old
- Tone: Surprised, funny, dramatic
- Speed: Normal
- Stability: High
```

**Résultat attendu :** Fichier MP3 avec la voix

---

## 7. Soundraw - Générer une musique amusante

**Prompt (via interface) :**
```
Music settings:
- Genre: Funny/Comedy
- Style: Kids animation
- Mood: Playful and silly
- Duration: 35 seconds
- Instruments: Light piano, xylophone, percussion
- Energy: Medium-high
- Tempo: Upbeat
```

**Résultat attendu :** Fichier MP3 avec la musique

---

## 8. CapCut - Auto-édition AI

**Étapes :**
```
1. Importer la vidéo brute
2. Clicker sur "Auto Captions"
3. Clicker sur "Auto Cut" pour supprimer les silences
4. Ajouter des stickers et émojis drôles
5. Ajouter la musique Soundraw
6. Ajouter des transitions entre les scènes
7. Exporter en 1080p

Durée totale : ~20 minutes
```

**Résultat attendu :** Vidéo montée et prête à publier

---

## 9. Descript - Édition basée sur les transcripts

**Workflow :**
```
1. Importer la vidéo brute
2. Cliquer sur "Auto Transcribe"
3. Descript génère automatiquement le transcript
4. Couper les parties inutiles directement dans le texte
5. Ajouter des visuels ou des sons
6. La vidéo s'ajuste automatiquement
7. Exporter en MP4
```

**Résultat attendu :** Vidéo éditée en quelques clics

---

## 10. Synthesia - Créer un avatar AI

**Workflow :**
```
1. Choisir un avatar cartoon enfantin
2. Écrire ou importer un script
3. Choisir une voix (ElevenLabs)
4. Sélectionner un décor
5. Générer la vidéo (5-10 minutes)
6. Télécharger en MP4

Résultat : Une vidéo avec un personnage AI qui parle
```

---

## 11. Runway - Améliorer les visuels

**Commande :**
```
Tools disponibles:
- Upscaling (améliore la qualité 2x ou 4x)
- Background remover (change le décor)
- Inpainting (ajoute des éléments)
- Video translation (sous-titres auto)

Utilisation:
1. Importer votre vidéo
2. Sélectionner "Upscale"
3. Choisir 2x ou 4x
4. Générer (2-5 minutes)
5. Télécharger
```

---

## 12. Opus Clip - Publier rapidement sur TikTok/Reels

**Workflow :**
```
1. Importer votre vidéo (ou URL YouTube)
2. Sélectionner une portion de 15-60 secondes
3. AI ajoute automatiquement :
   - Sous-titres
   - Transitions
   - Émojis
   - Musique libre
4. Cliquer sur "Publish"
5. Partager sur TikTok, Instagram Reels, YouTube Shorts
```

## Workflow d'une vidéo complète

### Minute 0-5 : Idée
```
ChatGPT: Génère 10 idées ✅
Choisir 1 idée ✅
```

### Minute 5-15 : Script
```
ChatGPT: Écris le script ✅
Copier-coller dans un document ✅
```

### Minute 15-30 : Visuels
```
DALL-E ou Midjourney: Génère 5-10 images ✅
Télécharger et organiser ✅
```

### Minute 30-40 : Voix et son
```
ElevenLabs: Génère la voix ✅
Soundraw: Génère la musique ✅
Télécharger les fichiers audio ✅
```

### Minute 40-60 : Montage
```
CapCut: Importe tout ✅
Assemble les images ✅
Ajoute la voix et la musique ✅
Ajoute les effets ✅
Exporte en MP4 ✅
```

### Minute 60-65 : Publication
```
Opus Clip: Publie automatiquement ✅
Sur TikTok, Reels, YouTube Shorts ✅
```

**Temps total : 65 minutes par vidéo**
**Si vous faites 1 vidéo par jour : 7 vidéos par semaine**
**Si vous faites 3 vidéos par jour : 21 vidéos par semaine**

## Astuces et bonnes pratiques

### Pour des vidéos de meilleure qualité :
1. Générer plusieurs versions avec AI
2. Choisir la meilleure
3. Améliorer avec Runway AI Upscaling
4. Exporter en 4K si possible

### Pour économiser du temps :
1. Créer des templates réutilisables
2. Générer 10 idées à la fois
3. Créer 5 scripts en une session
4. Batch montage (5 vidéos à la fois)

### Pour avoir plus de followers :
1. Publier régulièrement (chaque jour)
2. Utiliser des hashtags pertinents
3. Engager avec les commentaires
4. Adapter le contenu selon les réactions
